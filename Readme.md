# C++ DSA & Problem Solving

A collection of **C++ programs and Data Structures & Algorithms (DSA) practice problems** covering fundamental programming concepts, arrays, searching, sorting, pointers, linked lists, stacks, queues, and logical problem-solving.

This repository is created for learning, practicing, and improving **problem-solving and competitive programming skills** using C++.

---

## 📚 Topics Covered

The repository contains practice programs related to:

- C++ Fundamentals
- Arrays
- 2D Arrays
- Character Arrays
- Strings
- Functions
- Macros
- Pointers
- Double Pointers
- Searching Algorithms
- Sorting Algorithms
- Linked Lists
- Stacks
- Queues
- Subarrays
- Patterns
- LeetCode Problems
- Logical & Problem-Solving Questions
